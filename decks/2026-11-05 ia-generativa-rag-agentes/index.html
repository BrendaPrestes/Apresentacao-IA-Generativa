De onde vêm os fatos?

Onde entra o RAG?

Sem RAG o modelo responde de memória. Com RAG, ele consulta o guia da agência antes de responder.

1 · Recuperar

Busca no guia só os trechos que importam para a pergunta.

2 · Acrescentar

Coloca esses trechos dentro do prompt como base obrigatória.

3 · Gerar

O modelo escreve a resposta apoiado no que foi recuperado.

Aprofundamento técnico / 25
Treinamento e adaptação

Quando RAG não basta: ensinar o modelo.

Pre-training × Fine-tuning

  • Pre-training → modelo generalista
  • Fine-tuning → dados do domínio (domain-specific dataset)

Riscos

  • Esquecimento catastrófico → perde o que sabia
  • Overfitting → decora, não generaliza

PEFT · LoRA · QLoRA

  • LoRA → base congelada + pequenas matrizes treináveis
  • QLoRA → base quantizada em 4 bits + adaptadores LoRA
  • Menos memória e menos recursos
